# BEMANI Resource Manager

[English](README.md) · [GPL-3.0](LICENSE)

**本项目完全由Codex制作**

用于 macOS 和 Windows 的非官方 BEMANI 本地素材浏览与编辑工具。

- 预览、替换图像、动画、音频和 BGA。
- 按曲名、作曲家或编号搜索，预览带 BGA 和 Layer 的完整乐曲。
- 导出音频、图像及 MP4/GIF 动画。
- 编辑 Live2D 模型并实时预览；使用前请查看[运行库要求](docs/LIVE2D.md)。

支持中英文界面，修改保存为副本。
