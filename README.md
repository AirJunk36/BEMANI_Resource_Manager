# BEMANI Resource Manager

[简体中文](README.ch.md) · [GPL-3.0](LICENSE)

**This project was ENTIRELY made by Codex**

An unofficial browser and editor for local BEMANI resources on macOS and Windows.

- Preview and replace images, animations, audio and BGA.
- Search songs by title, composer or ID, and preview full songs with BGA and Layer.
- Export audio, images and MP4/GIF animations.
- Edit Live2D models with real-time preview; see [runtime requirements](docs/LIVE2D.md).

Supports English and Chinese. Changes are saved as copies.
