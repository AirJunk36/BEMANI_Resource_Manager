# Build and test

The repository contains source, not game data, game DLLs, Cubism Core or private
application artwork. Default icons are generated by `tools/build_icons.py`.
Packaged applications include the base parsing core; building from source
requires the development tools below.

## macOS

Install Python (3.13/3.14 recommended), the **macOS 26.0 SDK** and Swift 6.2
or newer. The deployment target is macOS 14.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python tools/build_icons.py
.venv/bin/python tools/build_macos.py
./start_mac.command
```

Use `IIDX_MACOS_SDK` and `IIDX_SWIFTC` to select a separate toolchain.
The interface language can be changed in the **Language / 语言** menu.

## Windows

Install x64 Python (3.13 recommended), the .NET 8 SDK and Windows development
tools. The ARM64 frontend uses x64 Python under Windows emulation.

```powershell
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python tools\build_icons.py
dotnet build native\windows\IIDXResourceViewer.csproj -c Release -p:Platform=x64 -p:RuntimeIdentifier=win-x64
$env:IIDX_VIEWER_HOME = (Get-Location).Path
.\build\windows\IIDXResourceViewer.exe
```

For ARM64, use `-p:Platform=ARM64 -p:RuntimeIdentifier=win-arm64`.
`start_windows.bat` also builds and launches the application.
Change the interface language using the list at the top right.

The single-EXE launcher is in `native/windows-launcher/`.
The scripts in `tools/windows/` prepare fixtures, build bundles and run native
tests. Set `IIDX_SHARED_PROJECT` to select the source tree. Tests default to
`%LOCALAPPDATA%\IIDXResourceViewerTest`; `cleanup-tests.ps1` accepts `-TestRoot`.
`prepare-test.ps1` uses `IIDX_GAME_ROOT` for fixtures.
After testing, run `cleanup-tests.ps1 -WhatIf` to review obsolete temporary files
before removing them with `cleanup-tests.ps1`.

Before distributing binaries, follow the [third-party source and license
requirements](../THIRD_PARTY_NOTICES.md#binary-distributions). Optional Live2D
components have [additional requirements](LIVE2D.md).

## Tests and shaders

```sh
python -m unittest discover -s tests -v
```

Set `IIDX_GAME_ROOT` and `IIDX_LIVE2D_ROOT` to local resource directories.
Tests that require unavailable private fixtures are skipped.
GPU tests need a working graphics session.
After editing GLSL, run `tools/build_shaders.py` with Qt Shader Tools' `qsb`
available to rebuild the `.qsb` shaders.

Keep private fixtures, runtime binaries, generated exports and personal paths
out of the repository.
